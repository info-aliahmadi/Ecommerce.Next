# Checkout Page - Full Backend Integration Plan

## Overview
Connect the checkout page to backend APIs for order creation, address management, and authentication.

## Files to Modify

### 1. `app/(home)/checkout/page.tsx` (main file)
- Add authentication gate (redirect to login if not authenticated)
- Load user's saved addresses on mount
- Pre-fill shipping form with user's name/email from session
- Add saved address selector in shipping step
- Save new addresses to backend when "Save Address" is checked
- Connect `handlePlaceOrder` to `OrderService.addOrder()`
- Show real order number from API response
- Handle loading/error states

### 2. Create `app/(home)/_services/CheckoutService.ts` (new file)
- `createOrder(order: OrderModel, items: CartItem[]): Promise<Result<OrderModel>>`
- Wrapper that builds the order payload from cart + form data

## Implementation Details

### Step 1: Authentication Gate
- Import `useSession` from `next-auth/react`
- Redirect to `/login?callbackUrl=/checkout` if not authenticated
- Pre-fill shipping form with `session.user.name` and `session.user.email`

### Step 2: Load Saved Addresses
- On mount, call `ProfileService.getUserAddresses()` if authenticated
- Add state: `savedAddresses`, `selectedAddressId`
- In shipping step, show a dropdown/selector above the manual form
- When user selects a saved address, auto-fill the form fields

### Step 3: Save Address on Checkout
- When "Save Address" checkbox is checked, call `ProfileService.addAddress()`
- Build `AddressModel` from the shipping form data
- Only save if user is authenticated

### Step 4: Place Order via API
- In `handlePlaceOrder`, build `OrderModel` from:
  - Shipping form → address fields
  - Payment form → payment method
  - Cart items → order items
  - Calculated totals → finalPrice, taxAmount, shippingAmount, discountAmount
- Call `OrderService.addOrder(order)`
- On success: show real order number, clear cart
- On error: show toast error, keep cart

### Step 5: Order Payload Structure
```typescript
const order: OrderModel = {
  addressId: selectedAddressId || 0,
  shippingMethodId: 1,
  orderStatusId: 1,
  shippingStatusId: 1,
  paymentStatusId: 1,
  paymentMethodId: paymentMethodMap[payment.method],
  finalPrice: total,
  totalAmount: total,
  taxAmount: tax,
  shippingAmount: shippingCost,
  discountAmount: discountAmount,
  customerIp: '',
  orderNotes: [],
  // ... other required fields
};
```

### Step 6: Translation Keys
Add to all locale files (en, fa, ar):
- `selectSavedAddress` - "Select a saved address"
- `useNewAddress` - "Use a new address"
- `orderFailed` - "Failed to place order"
- `loginRequired` - "Please login to continue"
