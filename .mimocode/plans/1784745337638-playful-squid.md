# Plan: Extract Shared LoginForm Component

## Goal
Create a single `LoginForm` component that both the login popup and login page use, eliminating ~400 lines of duplicated code.

## Analysis of Differences

| Aspect | Login Popup | Login Page |
|--------|-------------|------------|
| Container | `<Dialog>` | Full page with decorative left panel |
| Success action | `setLoginOpen(false)` + `resetForm()` | `router.push(callbackUrl)` + `router.refresh()` |
| Error display | `toast.error()` | Inline `<motion.div>` |
| Links | "Register" (opens popup) + "Go to full login" | "Register" as `<a href="/register">` |
| Header icon | `<LogIn>` | `<Lock>` |
| Back button | None | Arrow left to home |

## Implementation

### 1. Create `app/(home)/_components/pages/login-form.tsx`

A self-contained form component that handles all state and logic:

```tsx
interface LoginFormProps {
  onLoginSuccess?: () => void;    // Called after successful login
  onError?: (msg: string) => void; // Called on error (optional, falls back to internal state)
  showInlineError?: boolean;       // Show error inline vs toast only (default: false)
  idPrefix?: string;               // Prefix for input IDs (default: "login")
}
```

**Internal responsibilities:**
- All state (activeTab, email, password, phone, otp, loading, etc.)
- `handleEmailLogin` - calls `signIn('credentials', ...)` then `onLoginSuccess()`
- `handleSendOtp` - sends OTP via `/api/auth/send-otp`
- `handleOtpLogin` - calls `signIn('otp', ...)` then `onLoginSuccess()`
- The entire Tabs UI (email tab + phone tab)
- Error display (inline if `showInlineError`, toast otherwise)

**Renders:**
- Tabs with Email + Phone tabs
- Email form: email input, password input with toggle, remember me checkbox, submit button
- Phone form: phone input with +98 prefix, OTP input (after send), resend countdown, submit button
- Error message display (conditional on `showInlineError`)

### 2. Update `app/(home)/_components/pages/login-popup.tsx`

Replace all form logic with:
```tsx
import LoginForm from './login-form';

<Dialog ...>
  <DialogContent>
    {/* Header with LogIn icon + title */}
    <LoginForm
      onLoginSuccess={() => { setLoginOpen(false); resetForm(); }}
      onError={(msg) => toast.error(msg)}
    />
    {/* Links: Register + Go to full login */}
  </DialogContent>
</Dialog>
```

### 3. Update `app/(home)/login/page.tsx`

Replace all form logic with:
```tsx
import LoginForm from '../_components/pages/login-form';

{/* Left decorative panel - stays as is */}

{/* Right side */}
<div>
  {/* Back button */}
  {/* Header with Lock icon + title */}
  <LoginForm
    onLoginSuccess={() => { router.push(callbackUrl); router.refresh(); }}
    showInlineError
  />
  {/* Register link */}
</div>
```
